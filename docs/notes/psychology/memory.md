# 记忆与学习

记忆不是把信息「存进硬盘」，而是每次提取时重新拼装一次。理解了这一点，复习方法就会完全不同。

## 记忆的三个阶段

| 阶段 | 发生了什么 | 影响因素 |
| --- | --- | --- |
| 编码 | 信息进入工作记忆并与已有知识建立联系 | 注意、加工深度 |
| 存储 | 神经连接被巩固 | 睡眠、间隔、情绪 |
| 提取 | 按线索重建记忆 | 练习方式、情境 |

!!! note "加工深度"
    同样读一页书，只划线和合上书自己讲一遍，效果差很多。前者是浅加工，后者强迫你建立联系，属于深加工。

## 间隔效应

把同样的学习总量分散到多天，比集中在一晚记得更牢。原因是每次复习都发生在「有点遗忘」的时候，提取本身会增强记忆。

一个可操作的安排：

| 时间 | 做什么 |
| --- | --- |
| 当天 | 用自己的话复述一遍要点 |
| 第 2 天 | 不看笔记回忆框架 |
| 第 7 天 | 做几道题，检查薄弱点 |
| 第 30 天 | 快速过一遍公式和错题 |

## 提取练习

**测试比重复阅读更有效。** 合上书回忆、给别人讲、做旧题，都是提取练习。

!!! tip "费曼技巧的一个版本"
    假装要给一个完全没学过的人讲清楚这个概念。卡住的地方，就是你没真正理解的地方。回去补上，再讲一遍。

## 睡眠与巩固

睡眠期间海马体会把白天的记忆「重放」给大脑皮层。熬夜换来的学习时间，往往以第二天的记忆巩固为代价。

## 我的复习清单

- [x] 每天留 20 分钟做「无笔记回忆」
- [x] 错题只记「错在哪一步」，不抄整题
- [ ] 每周日整理一次本周的模糊概念
- [ ] 考前只翻自己的错题和公式表

> 记忆的高手不是记得多，而是知道什么时候该忘、什么时候该重新调出来。
