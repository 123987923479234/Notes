# 阅读摘录

一些读到时停下来想了很久的句子，以及当时的想法。

## 关于学习

> 学习不是记忆，而是把新东西接到旧东西上。

这句话解释了为什么「看懂了」和「能讲出来」之间差着一条河：看的时候是别人的结构，讲的时候才需要自己的结构。

> 如果你不能简单地解释一件事，说明你还没有真正理解它。

——常被归到费曼名下的一句话。用来做自测很好：合上书，试着用三句话讲清楚。

## 关于写作

> 写作是思考的显影液。

写笔记最大的收获不是那页纸，而是写的过程中被迫补上的逻辑漏洞。

## 关于时间

> 我们高估一天能做的事，低估一年能做的事。

所以计划要按周排，不要按天排。
